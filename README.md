# Skyline Weather

A responsive weather dashboard built with React. Search any city to see the current temperature, condition, humidity, pressure, wind speed, and sunset time.

## Run locally

```bash
npm install
npm start
```

Open [http://localhost:3000](http://localhost:3000).

## Build for production

```bash
npm run build
```

Weather data is provided by the free [Open-Meteo](https://open-meteo.com/) geocoding and forecast APIs. No API key is required.
